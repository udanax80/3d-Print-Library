# Choose

Before you slice anything, settle three things:

1. **The model:** where it came from and what its license allows. See [Model sources & licenses](model-sources.md).
2. **The printer:** which machine in the fleet suits the size, material, and color count. See [Printer selector](printer-selector.md) and the [Fleet comparison](../fleet/index.md).
3. **The material:** what the part has to survive (heat, UV, impact, flex). See the [Material matrix](../materials/index.md).
