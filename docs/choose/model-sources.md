# Model sources & licenses

## Where to find models

| Source | Good for | Notes |
|---|---|---|
| [Printables](https://www.printables.com/) | Functional parts, well-documented remixes | Run by Prusa. Many models include print settings and "makes" photos. |
| [MakerWorld](https://makerworld.com/) | Ready-to-print 3MF projects, multicolor | Run by Bambu Lab. 3MF projects carry plate and filament setup, so **re-slice for non-Bambu printers**. |
| [Thingiverse](https://www.thingiverse.com/) | Large legacy library | Older uploads vary a lot in quality. Check the comments and makes before printing. |
| Manufacturer / CAD sites | Exact-fit parts (brackets, mounts) | Prefer official STEP files when you'll be modifying the part. |
| Converters (e.g. BrickForge, from my guide library) | Brick-compatible parts and MOCs | Capabilities as described by the tool; **not independently verified**. Check fit and tolerances on a small test first. |

!!! note "3MF vs STL vs OBJ"
    **STL** is geometry only. **3MF** can carry plates, colors, modifiers, and slicer settings. **OBJ** can carry color through a companion **MTL** file, so keep them together when importing. (From my *OBJ vs. STL in Bambu Studio* guide; import behavior varies by slicer version.)

## Licenses: can I share, remix, or sell it?

Most community models use [Creative Commons licenses](https://creativecommons.org/licenses/). Read them from the model page every time, because uploaders change them.

| License tag | Share prints / files | Remix | Sell prints |
|---|---|---|---|
| CC BY | ✅ with credit | ✅ | ✅ |
| CC BY-SA | ✅ with credit | ✅ same license | ✅ |
| CC BY-NC / BY-NC-SA | ✅ with credit | ✅ (NC-SA: same license) | ❌ non-commercial |
| CC BY-ND / BY-NC-ND | ✅ unmodified only | ❌ | ND: ✅ · NC-ND: ❌ |
| Platform "Standard Digital File License" or custom | Read the terms | Usually ❌ | Usually ❌ |

!!! warning "Not legal advice"
    This table is a quick orientation. The license text on the model page is what counts. Some designers also sell separate commercial licenses.

**Habit worth keeping:** record source URL, designer, license, and date downloaded next to every model you keep. (My private dashboard has a *Model licenses* tracker for this.)
