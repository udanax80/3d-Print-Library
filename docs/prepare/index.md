# Prepare

Everything between "I have a model" and "press print":

- **[Calibration sequence](calibration.md)**: tune each new filament on each printer once, then save the profile.
- **[Slicer tips](slicer-tips.md)**: seam placement, support tuning, and strength settings.
- **[Multi-material planning](multi-material.md)**: tool changer vs AMS/CFS, purge, and support-interface pairs.

**Pre-flight checklist**

- [ ] Right printer for size, material, and colors ([selector](../choose/printer-selector.md))
- [ ] Filament dry ([drying](../materials/drying-storage.md)); right nozzle (hardened for CF/GF)
- [ ] Profile matches the exact filament and nozzle
- [ ] Plate clean (IPA, or dish soap and water for PEI) with the right release agent or glue
- [ ] Preview checked: seams, supports, first layer, travel
- [ ] Enclosure lid/door set correctly for the material (open for PLA, closed for ABS/ASA/PC/PA)
