# Jon's Print Lab

**A shared 3D printing reference, organized the way a print actually happens:**
Choose → Prepare → Print → Fix → Finish → Maintain.

!!! tip "Search first"
    Press ++slash++ or ++s++ (or click the search box at the top) and type a symptom, material, or printer, such as `stringing`, `PETG drying`, `K2 Plus`, or `support interface`.

## The lifecycle

| Stage | Go here when you're asking… |
|---|---|
| **[Choose](choose/index.md)** | Where do I get a model, can I share or sell it, and which printer should run it? |
| **[Fleet](fleet/index.md)** | What can each printer actually do? |
| **[Materials](materials/index.md)** | Which filament, what temperatures, does it need drying or an enclosure? |
| **[Prepare](prepare/index.md)** | How do I calibrate, set seams and supports, and plan multi-material jobs? |
| **[Fix](fix/index.md)** | Something went wrong. What's the likely cause? |
| **[Design](design/index.md)** | I'm modeling a part. What tolerances, holes, orientation, and walls should I use? |
| **[Finish](finish/index.md)** | Support removal, sanding, smoothing, painting, inserts. |

!!! warning "How to read the numbers on this site"
    Every temperature, time, and dimension here is a <span class="badge-start">starting point</span> taken from widely used ranges and manufacturer guidance, with sources linked. **The filament maker's label and your printer's own profile come first.** Test on a small part, change one thing at a time, and write down what worked.
