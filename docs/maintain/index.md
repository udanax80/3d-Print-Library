# Maintain: maintenance checklist

A generic schedule that works across the fleet. **The manufacturer's maintenance page for each printer wins** where it differs. Bambu: [X1 Maintenance Recommendation](https://wiki.bambulab.com/en/x1/maintenance/basic-maintenance). Prusa (good general reference): [Regular printer maintenance](https://help.prusa3d.com/article/regular-printer-maintenance-mk4-s-mk3-9-s_419000).

## Every print / daily
- [ ] Clean the plate (IPA wipe, soap and water for PEI when grip drops)
- [ ] Clear purge waste, poop chute, and wiper
- [ ] Check the nozzle for blobs or wrap. Watch the first layer

## Weekly (or ~50 print hours)
- [ ] Brush or wipe the nozzle and silicone sock. Check the sock for tears
- [ ] Clean dust and filament bits from rails, rods, and the bed area
- [ ] Check AMS/CFS/feeder paths for filament dust and shavings. Look at PTFE tube ends for wear
- [ ] Check desiccant in AMS/CFS units and dry boxes

## Monthly (or ~200 hours)
- [ ] Lubricate rods/rails/lead screws **only as specified** for that printer
- [ ] Check belt tension and pulley grub screws
- [ ] Clean extruder gears. Check the cutter (AMS/CFS) and filament sensors
- [ ] Clean fans (hotend, part cooling, chamber) and check the chamber/carbon filter
- [ ] Tool changers (U1, Creator 5 Pro): clean docks and wipers. Re-run tool-offset calibration

## Every 3–6 months / as needed
- [ ] Replace the nozzle (sooner with CF/GF in brass or stainless)
- [ ] Replace carbon/HEPA filters per the maker
- [ ] Re-run full calibration (bed mesh, input shaping, flow dynamics)
- [ ] Check wiring and cable chains for wear. Tighten frame screws
- [ ] Cold pull if extrusion degrades. See e.g. [Prusa KB: Cold pull](https://help.prusa3d.com/article/cold-pull-26702-mk4s-13702-mk4-28702-mk3-9s-21702-mk3-9-23702-mk3-5-28702-mk3-5s-17702-xl_445071) (method varies by hotend, so check your printer's guide)

## Spares worth keeping on hand
Nozzles (including hardened), silicone socks, PTFE tube, wiper/brush, AMS/CFS cutter blade, build plate, thermal paste or hotend kit, belts, desiccant, glue stick, IPA.
