# Recent prints

Project files you can open in Bambu Studio. Each card lists the printer, material, layer height, and scale, then buttons for the `.3mf` downloads.

Files are [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/): share and adapt them with credit, non-commercially, under the same license.

!!! tip "Direct file URLs"
    Every file under `prints/` is copied into this site on build, and the same bytes are on git branch `main`.

    - GitHub Pages (after deploy): <https://udanax80.github.io/3d-Print-Library/prints/>
    - Catalog on this site: [prints/index.json](index.json)
    - Catalog on `main`: <https://raw.githubusercontent.com/udanax80/3d-Print-Library/main/prints/index.json>

    A file at `prints/<path>` is `<base><path>` on either base. A dashboard on another website should fetch the raw catalog: GitHub sends `Access-Control-Allow-Origin: *` on raw files. Add a print by following [prints/README.md](https://github.com/udanax80/3d-Print-Library/blob/main/prints/README.md).
